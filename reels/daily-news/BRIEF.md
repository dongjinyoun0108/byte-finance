## Intent

The Reel twin of the daily @byte.finance.au carousel (Tue–Sat): the biggest overnight mover as the hook, the markets
board, three stories, follow CTA. Rendered every day in GitHub Actions from the same JSON the carousel uses, so it is a
**data-driven template**, not a one-off film. The user found the earlier code animations "not good" and pointed at a
"Claude x Motion Graphics" reel as the bar: constant motion, 3D card moves, UI mockups, camera moves — far more engaging
than plain mask reveals.

## Assets

- ../../render/assets/coin/*.png — 20 transparent 3D gold-coin mascot poses (1100x1100), the brand character.
- ../../render/assets/audio/theme.wav — original 112 BPM lo-fi house theme (music bed; cuts land on its beat).
- Fonts: Bricolage Grotesque (display) + Inter Tight (text), from node_modules/@fontsource-variable.
